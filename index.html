Post-intubation sedation

Failed airway plan (A → D)

  1. Plan A – Laryngoscopy/VL: max 3 attempts (+1 by most experienced). Optimize position, bougie, external laryngeal manipulation. Oxygenate between attempts.
  2. Plan B – 2nd-generation SGA: max 3 attempts; if oxygenating, stop and think (wake, intubate via SGA, or proceed).
  3. Plan C – Facemask: 2-person BVM + OPA/NPA, full paralysis. If oxygenating → wake / plan.
  4. Plan D – CICO: declare “Can’t intubate, can’t oxygenate”. Adult: scalpel–bougie–tube cricothyroidotomy (size 6.0 cuffed). Young children: needle cricothyroidotomy / surgical airway per local protocol.
